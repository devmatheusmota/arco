## Add your project

Open a pull request adding one row to the table above. That is the whole process — no
approval needed beforehand, no form to fill in first.

If you'd rather not clone the repo, open a
[showcase submission issue](https://github.com/Kc1t/alethe-agents/issues/new?template=showcase.yml)
instead and it will be added for you.

### Format

```markdown
| [Project name](https://link) | One line about what it is | [@yourhandle](https://github.com/yourhandle) |
```

Keep the description to a single line — what it is, not why it's great.

### What qualifies

- **Something real that exists.** Shipped, published, deployed, or at minimum a public repo
  someone else can look at. Not a plan.
- **Built with Arco as part of the workflow.** It does not have to be built *exclusively*
  in Arco, and it does not have to be big. A weekend project counts.
- **Public.** If you can't link to it, it can't go on the list.

Client work you can't disclose is welcome in spirit but not on the page — link a public
write-up instead if you have one.

### What doesn't

- Placeholder or dead links, unreleased vapourware, or a repo with a README and nothing else.
- Anything that would require someone to take your word for it.
